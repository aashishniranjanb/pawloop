## Features

- **Live Map**: Real-time visualization of all ecosystem nodes.
- **Feeding Stations**: Track, monitor, and maintain animal feeding locations.
- **Water Stations**: Dedicated tracking for hydration points, particularly critical in summer.
- **Volunteer Missions**: Gamified, dynamically assigned tasks for community engagement.
- **Reports**: Emergency and condition reporting for animals and stations.
- **Analytics**: Deep metrics on ecosystem health and volunteer activity.
- **Narrative Intelligence**: Generative AI-driven stories based on community impact.
- **Offline Sync**: Robust offline-first architecture using indexedDB for patchy networks.
- **Command Center**: Global view for ecosystem leads and administrators.
